# 判断事例 C04：カード利用の「速報版」メールだけで店舗名を断定しない

## Evidence（証拠）

| 項目 | 内容 |
|---|---|
| evidence class | REAL（実際のメール本文を確認） |
| observed_at | 2026-11-21 |
| scope | カード支出の検出・記録（月次カード明細チェック） |
| 事実 | 楽天カードのカード利用のお知らせは、本文に利用日・利用者・利用金額のみを含み、店舗名を含まない。店舗名を含むのは後から届く詳細版の「カード利用お知らせメール」である |
| source | 第2 Gmail アカウントの実メール（速報版の実例： 2026-11-20 利用分が 2026-11-21 に着信。本文は金額と日付のみ）／ 詳細版メールの本文確認 |

## 観察（何が起きたか）

- オーナーから「利用お知らせは結局 e-NAVI へのリンクだけではないのか」という疑問が出た。
- 実メールを確認すると、速報版についてはその通り（店舗名なし）だが、詳細版は本文に店舗名まで含むことが分かった。
- 教訓： **同じ「利用お知らせ」でも速報版と詳細版で証拠能力が違う。速報版だけで店舗名や用途を記録すると、誤った支出記録になる。**

## Recommendation（推奨）

- 店舗名・用途の記録は詳細版メールを正本とし、速報版は「金額と発生の早期検知」専用に使う。
- 詳細版がまだ届いていない支出は、店舗名を未確定として分け、推測で埋めない。
- 定期チェック（月次カード明細チェック）の手順には、速報版と詳細版の使い分けを明記する。

## Policy Candidate（候補）

| | 内容 |
|---|---|
| current | 利用お知らせメールがあれば店舗名まで分かったものとして記録し得る |
| proposed | 店舗名の根拠は詳細版メールに限定する。速報版のみの支出は「店舗名未確定」で保持し、詳細版の到着で確定させる |
| rationale | C02（カード明細が金額の正本になり得る）の内側でも、メールの版によって持つ情報が違うため。誤記録は経理の正本を汚す |

## Safety Floor チェック

- 本候補は「証拠の使い分け」の変更であり、安全フロアには触れない。
- カード会社・銀行への直接アクセスやログイン情報の保持は行わない（K08 の禁止事項と整合）。
