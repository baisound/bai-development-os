# 判断事例 C05：金額の根拠が一次情報にない収入・支出は「未確定」に分離し、合計に混ぜない

## Evidence（証拠）

| 項目 | 内容 |
|---|---|
| evidence class | REAL（Gmail 走査と経理シートへの記録作業で観測） |
| observed_at | 2026-11-21 |
| scope | 直近1年の入金・支払い履歴の管理（経理シート／弥生インポート） |
| 事実 | 収入側では、音楽配信の確認レポート（TuneCore）がメールに金額を含まず、金額はサービス側ダッシュボードにしかなかった。また外貨建ての入金（PayPal）は円額がメールに現れなかった。支出側でも、請求書メールに金額が含まれない従量請求が複数あった |
| source | 2026-11-21 の1年分走査の結果（入金5件・支払い40件の記録と、金額未確定として分離した項目群）／ 経理シートの管理タブに残した除外理由 |

## 観察（何が起きたか）

- 走査では「存在は確認できたが金額がメールで確定できない」項目が、収入・支出の両方に繰り返し現れた。
- これらを推計（為替換算など）で埋めると、合計額が根拠のない数字になり、後から正本（ダッシュボード、カード明細）と突き合わせたときに差分の説明ができなくなる。
- 実際に取った運用： 金額が確定したものだけを弥生インポート用に載せ、未確定のものは管理側に理由つきで分離して保持した。
- 教訓： **「取引の存在」と「金額の確定」は別々に扱う。存在が分かっても、金額の根拠が一次情報になければ未確定のままにする。**

## Recommendation（推奨）

- 収入・支出の走査では、各項目を「金額確定（根拠あり）／金額未確定（根拠待ち）」に必ず分け、未確定分は合計・月次集計に混ぜない。
- 未確定の理由（金額はダッシュボードのみ、円額が未確定、請求書に金額なし等）を項目ごとに残し、根拠が得られた時点で確定へ移す。
- 為替換算による推計額を、正本の金額として計上しない。

## Policy Candidate（候補）

| | 内容 |
|---|---|
| current | 金額が分からない項目の扱いが、その都度の判断になっている |
| proposed | 金額の根拠が一次情報（領収書、カード明細、サービス側の確定通知）にない項目は、一律「未確定」に分離し、合計と仕訳から外す。根拠が得られたら確定へ移行する |
| rationale | C02（カード明細が金額の正本）の裏側の原則。確定した数字だけが正本の合計を作る、という一貫性を保つため |

## Safety Floor チェック

- 本候補は記録の厳密さに関するもので、安全フロアには触れない。
- 未確定項目を「ないもの」として捨てる話ではない。存在と理由は保持し、確定待ちとして追跡する。
