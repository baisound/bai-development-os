# 『訳あり裁判』エンディング破壊的監査

**推奨は案1「最初の一本は、おばあちゃんへ」。** 冒頭で少年が異議を唱えたのは、祖母の誕生日を大切に思ったからだ。最後にその少年がいちばん先に祖母へカニを渡せば、抗議も判決も同じ気持ちから出たと分かる。祖母が受け取った瞬間なら、少年は心おきなく「閉廷！」と言える。

## 現行版で観客が受け取るもの

**現行の弱点は、判決を聞いた後に「みんなで食べる」ことを目で確かめる瞬間がないこと。** 大皿の量は中盤でも伝わる。最後にもう一度皿を見せたとき、観客が追う新しい動作は布を畳む手だけだ。また、無音で末尾だけを見た人には「閉廷。」は読めるが、何をどこが売っているCMかを持ち帰りにくい。声、句点、打音、暗転と段階を踏む現行の締めには落ち着きがある一方、少年のひと言の後にも終わりの合図が続く。

## 5つの別案

C09の開始はF635、終了はF811で、実尺は177フレーム（7.375秒）。各案はこの同じ枠を丸ごと使う。表中の **r0＝本編F635**、**r57＝本編F692（残りちょうど5秒）**、**r176＝最終F811**。商品名の表記は依頼文に合わせた「訳ありカニ」を仮コピーとする。

### 案1　最初の一本は、おばあちゃんへ

冒頭の「おばあちゃんの誕生日なのに？」に、少年自身の行動で答える。誕生日の主役がカニを受け取るまでを一続きに見せる。

| 相対フレーム | 映像・文字・音 |
|---|---|
| r0–56 | 祖母の席から見た食卓。手前に祖母の空いた取り皿、奥に少年と大皿。少年が取り皿を引き寄せる。部屋の音と陶器の擦れる音。 |
| r57–99 | 少年が一本だけ盛った取り皿を、両手で祖母へ滑らせる。皿の動きは横に一往復だけ。上の余白に小さく「日本直販の訳ありカニ」を出し、最後まで置く。 |
| r100–151 | 祖母が皿の縁に手を添え、「私が最初？」。少年が無言でうなずく。カニ、二人の目線、誕生日の主役が同じ画面に収まる。 |
| r152–176 | 祖母が一本を持ち上げたところで、少年が勢いよく「閉廷！」。短い字幕も同時に出す。声の語尾まで二人を映して切る。 |

**効く項目**　企画25・商品訴求30・ブランド適合性10。誕生日の発端を回収し、「家族で楽しめる」という商品の価値を、誰が誰に何を渡したかで示す。  
**弱点・リスク**　皿を渡すときに手指やカニ脚が変形すると、観客はそこを見る。固定画角で皿の移動を短くし、祖母の手が触れる瞬間を優先する。  
**実装の手間：中。** 新しい食卓の一芝居と祖母の短い台詞が要る。少年の閉廷ボイスは既存素材を使える。

### 案2　証拠品第一号は、カニ脚

音を消したスマホでも「何が訳ありで、何が便利か」を一読できる、縦一枚の証拠写真広告。裁判の道具立てを商品の説明に使う。

| 相対フレーム | 映像・文字・音 |
|---|---|
| r0–56 | 生成りの紙面にカニ脚一本の大きな切り抜き。上端に「証拠品 第一号」、その下に「日本直販の訳ありカニ」。紙を置く乾いた音を一度。 |
| r57–107 | 切り抜きの横に二行「冷凍期間が長め。／色がくすむ場合があります。」が現れる。商品名と説明は以後、同じ位置に残す。音読は入れない。 |
| r108–151 | 脚の下に青鉛筆で「ボイル済み。解凍するだけ。」と一行加わる。視線が説明から食べ方へ自然に下りる配置にする。 |
| r152–176 | 紙面の余白に少年の手書き風の「閉廷！」。本人の声を同時に一発。全情報がそろった一枚のまま終了。 |

**効く項目**　商品訴求30・ブランド適合性10。理由を限定し、「場合がある」も残せる。SNS評価12には、一時停止した一枚で意味が通る点が働きうる。  
**弱点・リスク**　説明量が増え、祖母の誕生日の余韻は薄い。文字を段ごとに消すと読み損ねるため、最後まで積み上げる。「ボイル済み。解凍するだけ。」は作中の説明に合わせた表記。  
**実装の手間：小。** 既存のカニ画像、静止画の組版、簡単な文字出し、既存音声で組める。

### 案3　「……もう一本。」を証言にする

殻から身が抜ける小さな音に、家族も観客も耳を澄ます。祖母が自然におかわりを求めた事実を、商品のいちばん短い推薦文にする。

| 相対フレーム | 映像・文字・音 |
|---|---|
| r0–56 | 一転して卓上の接写。指がカニ脚の殻に触れたところから。音楽を引き、殻と皿が触れる小さな音を近くに置く。 |
| r57–106 | 一口分の身がすっと抜ける。固定の接写で繊維と湯気のない自然な食卓を見せる。誇張した破裂音は使わず、指と殻の擦れを合わせる。 |
| r107–143 | 別の手が小皿をもう一度そっと差し出す。祖母の声と同時に字幕「……もう一本。」。誰の手か分かるよう袖色を本編と合わせる。 |
| r144–176 | 差し出した小皿の奥に家族。余白に「日本直販の訳ありカニ」。最後は小皿が卓上に触れる一音。 |

**効く項目**　商品訴求30・AI表現20。食べたくなる質感を映し、声を張らずに「また食べたい」を演じる。  
**「閉廷！」を外す理由**　静かな卓上に耳を寄せた観客には、祖母の「もう一本」が食べた本人による評決になる。ここに少年の大声を続けると、せっかく聞き取ったおかわりの一言が脇に回る。  
**弱点・リスク**　ミュートでは殻の音が消える。字幕と小皿の再登場が読めることが前提。身の太さや抜け方を誇張すると商品への期待を誤らせる。  
**実装の手間：大。** 接写に耐える食品素材と同期した細かな効果音、祖母の声が必要。実物に即した身の量を確認できる素材が向く。

| r57–112 | 紙が自分で三度折れ、細長い箸袋になる。折るたびに紙の音。赤い落書きは同じ紙の上に残り、折り上がると袋の表に来る。 |
| r113–151 | 箸が袋にすっと収まる。少し引くと「おばあちゃん」の席札と食べる分のカニがあり、袋の脇に「日本直販の訳ありカニ」。 |
| r152–176 | 少年の「閉廷！」で一対の箸が袋から勢いよく顔を出す。声の終わりで静止。紙の音と号令でリズムを完結させる。 |

**効く項目**　AI表現20・企画25。一枚の紙の表裏、折り目、絵柄を通して保てれば、変形そのものが「裁判から食事へ」という意味を持つ。  
**弱点・リスク**　箸袋だけが記憶に残る危険がある。折り上がりを長く鑑賞させず、食べる分のカニと席札まで必ず引いて見せる。文字の崩れも目立つ。  
**実装の手間：大。** 紙の各段階を設計し、文字と落書きは位置を固定して合成する。新しい画風への切り替えも要る。

### 案5　木のスプーンで冒頭につなぐ

少年のスプーンをリプレイの合図にする。初見では家族が食べ始める寸前のオチになり、繰り返し再生では「閉廷！」の直後に冒頭の「異議あり！」が返ってくる。

|---|---|
| r0–56 | 少年の主観。中央に最後の一本を盛った取り皿。左右から二膳の箸が同時に伸び、一本の手前でぴたりと止まる。箸先が触れる「カチ」。 |
| r57–111 | 祖母の手が画面奥から一本をさらう。空振りした二膳を一拍残す。中央上に「日本直販の訳ありカニ」を表示。説明台詞は入れない。 |
| r112–151 | 冒頭と同じ側から撮った少年。空の皿をちらりと見て、口元が笑う。スプーンを冒頭と同じ高さへ上げる。 |
| r152–176 | 少年がカメラに向いて「閉廷！」。字幕と声を同期させ、語尾が収まる位置で切る。最終姿勢と画角を本編F0に合わせ、次の「異議あり！」へつなぐ。 |

**効く項目**　SNS評価12・企画25。音ありでは正反対の二声がつながり、無音でも二膳の空振りでオチが読める。繰り返し再生して初めて二つ目の笑いが出る設計。  
**弱点・リスク**　最後の一本だけが強く残ると、量が少ないようにも見える。食べ終えた殻を隅に置き、時間が経ったことを示す。リピートの効果は再生環境に依存する。  
**実装の手間：中。** 卓上の短い手芝居と、冒頭に姿勢を合わせる少年のカットが要る。顔やスプーンの位置が跳ねるとつなぎが目立つ。

## 採用判断

**第一候補は案1。** 他の商品にも使えるおいしさのコピーを足すより、この少年にしかできないことを一つさせたい。一本を祖母に譲れば、少年の抗議には優しさがあり、母が選んだ訳ありカニには誕生日のごちそうとしての行き先がある。「閉廷！」も、祖母に最初の一本が届いたことを見届けた少年から自然に出る。商品訴求30・企画25・ブランド適合性10の三項目を、同じ動作で狙える。

**次点は案2。** 新規の人物芝居を用意しづらい場合や、ミュートで見た人に「訳あり」の理由と販売元を正確に残したい場合はこちら。食卓の芝居の出来に左右されず、静止一枚で商品の理解を確かめられる。

配点は依頼記載の100点制に従った。公式フォロー＆リポスト3点は応募運用の項目で、各案への加点には含めていない。SNS評価12点に関する記述は狙う反応で、2026年12月1日〜7日の公開実績は現時点では未確定。5案はいずれも未制作。今回の作業はローカルの読み取り検証と本レポートの作成まで。
