# 経理の仕訳ルール（個人事業主・弥生インポート対応）

## 1. 弥生インポート形式（やよいの青色申告 オンライン・個人事業主）

- 27列（A〜AA）の形式で作成する。
- 1行完結の仕訳は識別フラグ「2000」。
- 摘要は30文字以内。
- 税区分の表記は弥生公式の一覧に従う（国内・適格請求書ありの課税仕入は「課対仕入込10%」など）。

## 2. 勘定科目の対応（借方）

| 対象 | 借方科目 | 備考 |
|---|---|---|
| AI・開発系SaaS（ChatGPT、Claude、ElevenLabs、Suno、GitHub等） | 消耗品費 | |
| Google のクラウド系（Google AI Pro、Google Cloud等） | 通信費 | |
| X Premium、Google Ads | 広告宣伝費 | |
| Amazon の事業用購入（開業準備分） | 消耗品費（補助： Amazon） | §5 の分類基準に従う |
| 来客・打合せ用の飲食・お茶・お菓子 | 接待交際費／会議費 | §4 参照 |

- 貸方は原則として一律「未払金」とし、補助科目に支払手段（クレジットカード等）を入れる。
- 個人立替の場合は「事業主借」、事業口座からの引落は「普通預金」を使う余地がある（シートの勘定科目・設定に準拠）。

## 3. 税区分のデフォルト

- 借方の税区分は原則「対象外」から始める（海外サービス等で適格請求書がない場合の安全側）。
- 国内の適格請求書（インボイス）がある場合に限り「課対仕入込10%」へ変更する。
- 貸方（未払金）には税区分を入れない（弥生オンラインの仕様）。

## 4. 飲食費ルール（2026-11-21 オーナー確認済み）

個人事業主の飲食費は、相手と目的で扱いが決まる。

- **本人のおやつ・食事は家事費**。経費にできない。管理表では「対象外／個人」に分類する。
- **福利厚生費は原則として従業員がいる場合のみ**。現状は代表1人のため使えない（将来、従業員を持ったら再判断する）。
- **来客・打合せに出すお茶・お菓子・飲食は経費計上できる**。接待交際費／会議費として計上する。個人事業主に接待交際費の上限はなく、条件は事業関連性があること。
- Amazon 等の購入分類でも同じ基準を使う： **自分用 ＝ 対象外／個人、来客・打合せ用 ＝ 接待交際費**。

## 5. Amazon 支出の分類基準

- 事業・開業準備に使うもの（機材、制作・開発用品、事業用書籍、事務用品等）→ 開業準備として計上（借方 消耗品費／補助 Amazon、貸方 未払金、摘要に「開業準備 Amazon …」と明記）。
- 自分用の飲食・日用品 → 対象外／個人（支払い履歴には記録するが弥生へは入れない）。
- 事業関連性が判断できないもの → 「事業関連性要確認」として支払い履歴のみに入れ、オーナーの判断を仰ぐ（勝手に経費化しない）。

## 6. 金額の正本

- 金額は推測で入れない。円金額が確認できる資料（注文確認メール、カード明細メール等）が正本。
- 外貨建てのみ確認できる場合は、カード明細の円金額が確定するまで弥生インポート用へ入れない。
- 決済失敗・解約済みのものは仕訳を作らない（支払いが発生していないため）。
- メールで確認できる範囲が検出の限界であることを、報告時に必ず添える。

## 検証手順

- インポート前に、弥生インポート用の行数と借方合計を読み戻して検算する。
- 分類に迷った支出は経費化せず「要確認」に倒し、月次再チェックでオーナーに提示する。
