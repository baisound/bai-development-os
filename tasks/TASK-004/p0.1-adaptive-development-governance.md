# TASK-004 P0.1 — Adaptive Development Governance / Governance Economy

## Objective

Make development depth proportional to the requested work so BAI Development OS can host projects of different size and risk without wasting tokens or weakening critical assurance.

## Owner requirement

The system must change how agents are run according to:

- system size,
- function/change size,
- whether the function is core or peripheral,
- failure impact,
- reversibility,
- design novelty,
- cross-project/security/authorization/state/migration risk.

Core and foundation functionality requires stronger testing and Critic participation. Small peripheral changes must not be forced through the same heavy ceremony.

## Implemented foundation

- `src/governance/adaptive-development-profile.mjs`
- `schemas/governance/adaptive-development-profile.schema.json`
- `tests/governance/adaptive-development-profile.test.mjs`
- `specifications/Adaptive_Development_Governance_Specification_Ver1.0.md`

## Important boundary

This does not change the permanent model-selection policy. It selects workflow and assurance depth. Model routing remains a separate concern.
